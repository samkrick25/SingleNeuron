code for visualizing and finding targeted region frequencies of single neuron reconstructions acquired from the Allen Institute for Brain Science


depends on numpy, pandas, nibabel, and brainrender python packages, install with pip, also needs allen ccfv3 10um nii file found [here](https://allen-brain-cell-atlas.s3.us-west-2.amazonaws.com/index.html#image_volumes/Allen-CCF-2020/20230630/)


examples for how to load data, get frequency DataFrame, and visualize single cells can be found in example.py, Spyder 6 IDE is recommended
